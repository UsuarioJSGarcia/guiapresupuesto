# guiapresupuesto
GUIAPRESUPUESTAL PROCEDIMIENTOS

Herramienta personal para ordenar ingresos y gastos y salir de deudas.

- `DIAGNOSTICO.md`: diagnóstico actual y plan recomendado.
- `datos.json`: tus ingresos, gastos y deudas. Edítalo con tus números reales.
- `planificador.py`: calcula el diagnóstico, compara los métodos avalancha y bola de nieve, y simula refinanciar.

```bash
python3 planificador.py            # escenarios por defecto
python3 planificador.py 3800000    # ¿qué pasa si pago 3,8M al mes?
```
