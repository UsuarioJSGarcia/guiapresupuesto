# guiapresupuesto
GUIAPRESUPUESTAL PROCEDIMIENTOS

Herramienta personal para ordenar ingresos y gastos y salir de deudas.

- `DIAGNOSTICO.md`: situación actual y plan recomendado.
- `NEGOCIACION.md`: qué pedirle al banco y cómo hablar con los acreedores.
- `INGRESOS_EXTRA.md`: cómo generar más ingresos como ingeniero de software.
- `datos.json`: ingresos, gastos, deudas y crédito bancario. Edítalo con tus números reales.
- `planificador.py`: calcula el flujo de caja y simula el pago de deudas con y sin crédito bancario.

```bash
python3 planificador.py            # escenarios con lo que hoy te queda para deudas
python3 planificador.py 4000000    # ¿qué pasa si destino 4M al mes a deudas?
```
